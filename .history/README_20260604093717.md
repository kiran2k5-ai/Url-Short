# LinkNest – AI Powered URL Shortener SaaS

## Overview

LinkNest is a modern URL shortening platform that allows users to create, manage, analyze, and share shortened URLs efficiently.

The platform provides secure authentication, custom short URLs, QR code generation, analytics tracking, bulk URL uploads, and a professional dashboard for managing links.

The project is built using the MERN stack and follows a modular architecture with a React frontend and Express.js backend.

---

# Problem Statement

Long URLs are difficult to share, track, and manage.

Traditional URL sharing platforms provide limited analytics and poor management capabilities.

LinkNest solves this by providing:

* Secure user authentication
* Short URL generation
* Custom aliases
* QR code generation
* Analytics dashboard
* Bulk URL creation
* Link management interface

Create .env

npm run dev

npm install

npm run dev
