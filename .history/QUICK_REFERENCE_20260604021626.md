## Common Issues & Solutions

### Issue: Pages not loading
**Solution**: Clear browser cache, reload http://localhost:5177/

### Issue: Dev server crashed
**Solution**: Run `npm run dev` again

### Issue: Styling looks off
**Solution**: Rebuild with `npm run build`

### Issue: Can't access protected pages
**Solution**: Login with valid credentials first
